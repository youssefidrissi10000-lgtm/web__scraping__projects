# Avito Laptops Scraper

A Python script that collects gaming laptop listings from Avito.ma.

## Tools
- Python
- Playwright
- pandas

## How to run
1. Install the libraries:
   pip install pandas playwright
2. Install the browser:
   playwright install chromium
3. Run the script:
   python avito_laptops_scraper.py

## Output
The script saves a file with 3 columns:
- tatle: the laptop title
- price_dh: the price in DH
- lien_prodwe: the link to the listing
